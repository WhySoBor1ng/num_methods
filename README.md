# Numeric methods lab 1

Реализация всех пунктов первой лабораторной работы:

1. LU-разложение с выбором главного элемента, решение СЛАУ, определитель и обратная матрица.
2. Метод прогонки для трехдиагональной СЛАУ.
3. Метод простых итераций и метод Зейделя.
4. Метод вращений Якоби для собственных значений и собственных векторов симметрических матриц.
5. QR-разложение и QR-алгоритм поиска собственных значений.

## Запуск

```bash
python main.py
```

Зависимость:

```bash
pip install numpy
```
